## これは何か

一度も政権を取れなかった党を、取れなかったまま三十四年動かす。
勝ち方は一つではない ── 議席、政権、党の統一のどれかを満たせばその幕は勝ちになる。

- 五つの山札（党務・国会・労働・地方・政権）と、政権に入ってから開く政策の献立
- 四つの派閥。路線を決めるたびにどこかが怒り、出口のある派閥は出て行く
- 十二回の総選挙。得票は六つの社会層と組織率から積み上げて計算する
- 憲法。三分の二を組めれば発議でき、護憲の側が崩れれば向こうが発議する
- 文庫 ── 盤に出てくる言葉（協会・代議員・総評・春闘・食管…）の解説と、
  衆参の議席図、選挙の履歴
